#  FlyRank Internship — Backend & AI Engineering

This repository documents my **Backend AI Engineering Internship** at **FlyRank AI**. It contains a series of completed assessments and technical assignments covering production-grade FastAPI web services, database persistence using the Repository Pattern with SQLite/PostgreSQL, containerized deployments with Docker, JWT authentication, and LLM engineering workflows integrated via **Portkey**, **RunPod**, and the **Claude API**.

Each assignment lives in its own directory with a dedicated `README.md` covering the project overview, requirements, implementation details, setup instructions, API documentation (where applicable), and testing steps.

## ⚙️ Getting Started

Each assignment is self-contained. To run a specific project:

1. **Clone the repository**
   ```bash
   git clone https://github.com/mazkar-224/Flyrank-internship-Backend-AI-Engineering-.git
   cd Flyrank-internship-Backend-AI-Engineering-
   ```

2. **Navigate to the assignment folder you want to run**
   ```bash
   cd Assignment-0X-project-name
   ```

3. **Follow the setup instructions in that folder's own `README.md`**, which includes environment setup, dependency installation, and run/test commands specific to that project.
